# Gruvbox Theme for ejchan

Тёмная цветовая схема в стиле Gruvbox для имиджборд на движке **ejchan**.

![Пример оформления](https://github.com/user-attachments/assets/c6b43ae8-3760-4fe7-b787-f9e0f97a3bf8)

## Установка

1. Скачайте файл [`gruvbox.css`](gruvbox.css).
2. Перейдите на [Ejchan](https://ejchan.site/).
3. Откройте настройки (обычно значок шестерёнки сверху страницы).
4. Найдите поле **«Свой CSS»** (или «Custom CSS»).
5. Вставьте всё содержимое файла `gruvbox.css` в это поле.
6. Сохраните настройки.
